# Аделина — голосовой Discord-бот

Бот для голосового канала Discord: слушает микрофон, распознаёт речь, играет музыку из Яндекс Музыки и отвечает голосом через YandexGPT + SpeechKit.

## Что умеет

- Голосовые команды по wake-слову «Аделина» (настраивается через `WAKE_WORDS`)
- Воспроизведение треков из Яндекс Музыки по названию/исполнителю
- «Просто музыка» — бесконечно играет хиты топ-чарта, пока не остановишь
- Пауза/пропуск/громкость/стоп голосом
- Ответы на вопросы: YandexGPT → озвучка голосом Алёны (SpeechKit TTS)
- Автовыход из канала, когда все люди ушли
- Slash-команды: `/join`, `/leave`, `/play`, `/stop`

## Требования

- Node.js >= 20 (проверено на Node 24)
- Windows/Linux/macOS
- Токены и ключи (см. ниже)
- `ffmpeg-static` ставится как npm-зависимость (внешний ffmpeg не нужен)

## Установка

```bash
npm install
cp .env.example .env
# заполнить .env
npm start
```

## Переменные окружения (.env)

| Переменная | Обязательна | Описание |
|---|---|---|
| `DISCORD_TOKEN` | да | Токен бота из Discord Developer Portal |
| `GUILD_ID` | нет | ID сервера для мгновенной регистрации слеш-команд; без него команды глобальные (до ~1 часа) |
| `YANDEX_CLOUD_API_KEY` | для STT/TTS | API-ключ сервисного аккаунта Yandex Cloud |
| `YANDEXGPT_FOLDER_ID` | для GPT | ID каталога Yandex Cloud |
| `YANDEX_MUSIC_TOKEN` | для музыки | OAuth-токен Яндекс Музыки |
| `STT_LANGUAGE` | нет | Язык распознавания, по умолчанию `ru-RU` |
| `TTS_VOICE` | нет | Голос синтеза, по умолчанию `alena` |
| `WAKE_WORDS` | нет | Список wake-слов через запятую, по умолчанию `аделина,adelina,аделинка,аделя,адель` |

### Как получить Yandex Cloud API-ключ

1. Создать платёжный аккаунт и каталог в Yandex Cloud.
2. Создать сервисный аккаунт и выдать ему роли:
   - `ai.speechkit-stt` — распознавание речи
   - `ai.speechkit-tts` — синтез речи
   - `ai.languageModels.user` — YandexGPT
3. Создать для сервисного аккаунта API-ключ (`AQVN...`) — это `YANDEX_CLOUD_API_KEY`.
4. ID каталога — `YANDEXGPT_FOLDER_ID`.

## Использование

1. Зайти в голосовой канал Discord.
2. `/join` — бот подключится и начнёт слушать.
3. Говорить команды, начиная с wake-слова:

| Фраза | Действие |
|---|---|
| «Аделина, включи everything black» | поиск и воспроизведение трека |
| «Аделина, включи моя волна» | играет хиты топ-чарта, пока не остановишь |
| «Аделина, дальше» | следующий трек |
| «Аделина, тише» / «громче» | громкость музыки |
| «Аделина, стоп» | остановить музыку |
| «Аделина, выйди» / «уйди» / «пока» | выйти из канала |
| «Аделина, сколько будет два плюс два» | вопрос к YandexGPT, ответ голосом |

`/leave` — выгнать бота из канала.

## Архитектура

```
src/
  index.js              Discord-клиент, слеш-команды, обработка фраз, сессии
  config.js             Конфиг из .env
  voice/
    connection.js       Подключение к голосовому каналу
    session.js          Один AudioPlayer, очередь трек/TTS, громкость, загрузка mp3
  listen/
    listener.js         Запись фраз из канала (opus → PCM), вызов STT
  stt/
    session.js          SpeechKit STT через синхронный HTTP (lpcm)
  tts/
    synthesize.js       Обёртка вокруг session.speakText
  music/
    client.js           API Яндекс Музыки: поиск, альбомы, ссылка на mp3
  commands/
    parse.js            Разбор текста: wake-слово, команды
    dispatch.js         Поиск и выбор трека, кандидаты, запуск воспроизведения
    translit.js         Транслитерация русской фонетики в латиницу
  assistant/
    llm.js              YandexGPT: вопросы, исправление транслита
    context.js          История диалога на пользователя
```

### Важные технические решения

- **Один AudioPlayer на соединение.** В `@discordjs/voice` 0.19.x соединение поддерживает только одну подписку плеера; второй плеер молча отписывает первый. Музыка и TTS идут через общий плеер и очередь.
- **Трек скачивается целиком в память** перед воспроизведением. Живой стриминг с CDN Яндекса обрывается посреди песни (`terminated`/`aborted`); полная загрузка ~0.5 сек на трек, это надёжнее.
- **STT — синхронный HTTP**, не WebSocket: WS-эндпоинты SpeechKit v1/v3 отдают 403 для этого аккаунта, а HTTP `stt:recognize` работает. Фраза копится в буфер, после тишины (700 мс) уходит целиком (лимит 55 сек).
- **Поиск Яндекс Музыки — через `type=all`.** Блок `best` даёт правильную сущность (трек или альбом), чего не даёт `type=track` (пример: «everything black» не находит Unlike Pluto). Треки альбома берутся из `/albums/{id}/with-tracks` (путь `/tracks` для синглов отдаёт 404).
- **Смешанный язык запроса.** STT пишет английские названия кириллицей («еверифинг блек»). Перед поиском запрос исправляется YandexGPT (лонг-пример), плюс генерируются транслит-кандидаты. Кандидаты сравниваются по совпадению слов + популярности (лайкам альбома), потому что у разных песен бывают одинаковые названия.
- **Громкость**: музыка `0.45`, TTS `1.6` (сырая озвучка SpeechKit тише музыки).

## Диагностика

Что смотреть в консоли при проблемах:

- `Готова: ...` — бот вошёл
- `Услышала (id): ...` — STT распознал фразу
- `Голос -> команда: ...` — wake-слово найдено, команда разобрана
- `Поиск «...»: треков N, best ...` — что вернул поиск
- `Кандидат «...»: score=..., лайков=...` — как выбирался трек
- `Выбран трек: ... (id ...)` — итог
- `[player] playing -> idle`, `[voice] ready -> ...` — состояние плеера

Частые проблемы:

| Симптом | Причина / решение |
|---|---|
| `STT 403` | У сервисного аккаунта нет роли `ai.speechkit-stt` |
| `TTS 403` | Нет роли `ai.speechkit-tts` |
| `YandexGPT 403/401` | Нет роли `ai.languageModels.user` или неверный folder_id |
| `Плеер: terminated/aborted` | Устаревший код со стримингом; трек должен скачиваться целиком |
| Нет звука, плеер `autopaused` | Несколько подписок плеера на одно соединение |
| Слеш-команды не видны | Не задан `GUILD_ID`, глобальная регистрация занимает время |
| Бот не реагирует на голос | Фраза не начинается с wake-слова; проверь `WAKE_WORDS` в `.env` (он переопределяет дефолт) |

## Ограничения

- YandexGPT отказывается от ряда тем и не матерится (политика модели, параметра отключения нет). `yandexgpt` отвечает свободнее, чем `yandexgpt-lite`.
- У SpeechKit TTS v1 нет параметра фильтра мата — он не поддерживается API.
- Ранжирование поиска Яндекс Музыки через API не совпадает с веб-интерфейсом; выбор компенсируется кандидатами и популярностью.
- Ссылка на mp3 живёт около минуты — качать нужно сразу после получения.
